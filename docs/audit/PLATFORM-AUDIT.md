# تقرير فحص صوتي قلمي — 30 أكتوبر 2026

التغييرات محلية في مستودعي الواجهة والخادم. لم يحدث push أو نشر على Vercel أو Render. لا يشمل هذا التدقيق إعادة تصميم الواجهة؛ التعديلات البصرية الأقدم في مساحة العمل سابقة لهذا التدقيق.

## معنى الحالات وحدود النتيجة

- **PASS**: اختُبر المسار المحدد ونجح.
- **FIXED**: ظهر خلل، عُدّل محليًا، ونجح اختبار يغطيه.
- **FAILED**: خلل باقٍ في النسخة أو البيئة المحددة.
- **BLOCKED**: تعذّر التحقق لعدم توافر الجهاز أو الخدمة أو الصلاحية اللازمة.

هذه نتائج الاختبارات المنفذة، وليست شهادة بأن كل نقرة وكل جهاز قد اختُبر. يميّز التقرير بين اختبار واجهة المتصفح، واختبار API/قاعدة البيانات، وفحص المصدر.

## البيئة وحماية البيانات

الواجهة React/TypeScript/Vite، والخادم FastAPI، والتخزين PostgreSQL. تحويل الكلام عبر Groq، والمساعد عبر Gemini. اختبارات الحسابات والمحتوى تمت على PostgreSQL مؤقتة ومعزولة، دون استخدام قاعدة الإنتاج. اختبار الخدمات الفعلية استخدم حساب ضيف جديدًا مخصصًا للتدقيق، وحفظ تقدم هذا الحساب وحده. لم تُعدّل حسابات الطلاب القائمة أو محتوى المعلم في الإنتاج.

استُخدم Chrome بملف متصفح معزول. التسجيل الآلي استخدم MediaRecorder الحقيقي وجهاز التقاط اختباري يعيد تشغيل ملف صوت تعليمي فعلي من المشروع. لم يُسجّل صوت من غرفة المستخدم. اختبارات المساعد والصوت الفعلية لم تستبدل ردود الخدمات بردود وهمية. اختبارات وحدات مزود Gemini تعزل الردود عمدًا لفحص العقود والأخطاء، ولا تُعد دليلًا على اتصال حقيقي.

## الأقسام التي فُحصت

فُحصت الشفرة ومسارات التنقل الأربعة عشر: الدخول، التعريف، لوحة الطالب، المهارات، التحدث، الكتابة، التعلم الذاتي، التقييمات، المعلم، اختيار الصف، مركز الألعاب، ولعبتا الكنز والغواص ولعبة المنطاد. شمل فحص الخادم المصادقة وJWT، عزل سجلات الطلاب، حفظ المحتوى، التعليقات، التقييمات، الاستبيانات، رفع الصوت والتكاملات الخارجية. ظهور الصفحة وحده لم يُحتسب نجاحًا لوظائفها الداخلية.

## ما يحتاج تحققًا يدويًا أو نشرًا معتمدًا

- **BLOCKED — أجهزة فعلية:** Safari/Firefox وiPhone/Android وميكروفون فعلي، جودة الالتقاط من الغرفة، تبديل أجهزة الصوت وتعليق/استئناف التطبيق. محاكاة مقاس الهاتف في Chrome لا تثبت دعم متصفح الهاتف.
- **BLOCKED — تكامل محلي بمفاتيح حقيقية:** لا توجد مفاتيح Groq/Gemini محلية؛ اختُبرت الخدمات فعليًا عبر Render بمفاتيح الخادم الحالية، واختُبرت معالجة الفشل محليًا. لم تُنسخ مفاتيح الإنتاج.
- **BLOCKED — نسخة منشورة محدثة:** التحقق من إصلاح metadata وإعادة محاولات Gemini على Render ينتظر موافقة المستخدم ثم نشر الخادم. نشر الواجهة وحدها لا يطبق إصلاحات Python.
- **BLOCKED — تغطية يدوية شاملة:** كل نافذة تعديل/حذف للمعلم، كل نشاط فرعي للتعلم الذاتي، جميع درجات التكبير وقارئات الشاشة، تحميل وضغط متزامن طويل، وتقييم تربوي شامل لجودة التصحيح. لم يُدّع اختبار كل عنصر تفاعلي.
- المساعد الحالي يرسل سؤالًا واحدًا لكل طلب؛ سياق محادثة متعدد الأدوار غير موجود في عقد API الحالي، ولم تُضف ميزة جديدة ضمن التدقيق.
- بقيت تحذيرات deprecation في مكتبات Python/Node؛ لا تمنع الاختبارات أو البناء الحالي.

## الأدلة وإعادة الاختبار

النتائج المرفقة: [المسارات الوظيفية](functional-results.json)، [الألعاب والتعلم الذاتي](learning-results.json)، [الخدمات الفعلية](live-provider-results.json)، [المقاسات](responsive-results.json)، [اختبارات الخادم](backend-tests.txt)، [اختبارات الواجهة](frontend-tests.txt). تتضمن نتائج الخدمات الفعلية محاولات 503 الفاشلة كما حدثت، ثم النجاح؛ لم تُحذف لإظهار نجاح مصطنع.

في إعادة التشغيل النهائية، تجاوز فيديو الغواص مهلة الاختبار الأولى (45 ثانية). أُعيد اختباره وحده بمهلة 90 ثانية للتشخيص، ونجح الفيديو وكل المراحل وزر الانتقال إلى المنطاد؛ لم يتغير كود الفيديو. حُفظت المحاولة الفاشلة في [إعادة الألعاب](learning-results.json)، والنجاح اللاحق في [إعادة الغواص](diver-retest-results.json)، مع [نتائج الألعاب الأولى](learning-initial-results.json). فشل المهلة لا يثبت تعطل تشغيل الفيديو في المنصة، لكنه جزء من سجل الاختبار.

سكربتات المتصفح بجوار التقرير. تحتاج Chrome وPlaywright وخادم واجهة وخادم API وقاعدة PostgreSQL **مخصصة للاختبار فقط**. يمكن ضبط `SAWTI_TEST_BASE` و`SAWTI_PLAYWRIGHT_MODULE` و`SAWTI_TEST_AUDIO`. لا تشغّل سكربتات الحسابات/تعديل المحتوى على إنتاج أو مستخدم قائم. سكربت live يحتاج ملف جلسة ضيف تدقيق خاصًا في tmp، غير مضمّن في المستودع. ملفات السجلات هنا لا تحتوي JWT أو مفاتيح API.

فحص الواجهة: `npm run check` ثم `npm run build` ثم `npx vitest run client/src/lib/store.test.ts client/src/lib/exercise-answer.test.ts`. فحص الخادم: `pytest test -q` مع `TEST_DATABASE_URL` لقاعدة مؤقتة فقط؛ بدونه تتخطى الاختبارات التي تحتاج قاعدة بيانات، فلا تعد هذه تغطية كاملة للتخزين.
